【アップロード方法】
1. GitHub のリポジトリ（THE-VIP-BAR）を開く
2. 「Add file」→「Upload files」をクリック
3. このフォルダ内の【すべてのファイル】をドラッグ＆ドロップ
   ※ フォルダごとではなく、中身を全部です
4. 画面下の「Commit changes」を押す

これで完了です。数分後に the-vip-bar.com に反映されます。
同名ファイルは自動的に上書きされます。

【地図が表示されない場合】
Google マップの埋め込みは、実際にインターネットに公開された状態
でのみ正常表示されます（ローカルでのプレビューでは表示されない
ことがあります）。
